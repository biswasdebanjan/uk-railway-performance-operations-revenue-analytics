# Segmentation Framework

## Time Bucket

| Segment | Definition |
|---|---|
| Morning Peak | 06:00–09:59 |
| Midday | 10:00–15:59 |
| Evening Peak | 16:00–19:59 |
| Off-Peak | Remaining hours |

## Booking Type

| Segment | Definition |
|---|---|
| Same Day | 0 days advance |
| Short Advance | 1–5 days |
| Planned | >5 days |

## Delay Severity

| Segment | Definition |
|---|---|
| On Time | 0 min |
| Minor Delay | 1–15 min |
| Moderate Delay | 16–30 min |
| Major Delay | 31–60 min |
| Severe Delay | >60 min |

Thresholds were selected from observed distributions and evaluated using statistical reasoning and business/operational validation rather than arbitrary visual binning.
